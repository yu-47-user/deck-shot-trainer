# Deck Shot Trainer

公式ツールのデッキスクリーンショットからカード画像をグリッド切り出しし、遊戯王の初手・展開ルート練習を行う静的Webアプリです。

## 初期機能

- デッキスクリーンショット画像アップロード
- メインデッキとEXデッキのグリッド切り出し
- 列数、行数、領域、カード間隔、カード比率、切り出し枚数の調整
- 切り出し結果プレビュー
- IndexedDB へのメイン/EXカード画像保存
- メインデッキから5枚ドロー
- EXデッキ画像一覧の参照
- 展開結果、課題タグ、メモの練習ログ保存
- ブラウザ内データ削除
- `noindex, nofollow` による検索避け

## 初期対象外

- サイドデッキ
- エクスポート/インポート
- Cloudflare Access
- OCR
- カード名自動認識
- 公式カードDB連携
- サーバー保存
- ユーザーアカウント
- 複数端末同期

## ローカル起動

```bash
cd /home/shiyo-wsl/projects/deck-shot-trainer/repo
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 主要ファイル

- `index.html`: 画面構造と `noindex` 設定
- `src/css/style.css`: レイアウト、レスポンシブUI、カードプレビュー表示
- `src/js/script.js`: 画像読込、Canvas切り出し、IndexedDB保存、ドロー、ログ管理
- `src/images/`: サンプル画像などの静的画像

Codex用の `AGENTS.md` と `PROJECT_PLAN.md` は、このリポジトリ用フォルダの外側に置きます。

## 保存仕様

カード画像と練習ログはブラウザの IndexedDB に保存します。サーバー送信は行いません。

ブラウザデータ削除、別ブラウザ、別端末では保存データを参照できません。初期版ではエクスポート/インポートを提供しません。

## 切り出し調整の考え方

メインデッキ領域とEXデッキ領域を分けて、画像全体に対する割合で位置とサイズを指定します。

- `左位置 %` / `上位置 %`: 切り出し領域の開始位置
- `領域幅 %` / `領域高 %`: 切り出し対象の外枠
- `列数` / `行数`: グリッド数
- `切り出し枚数`: 実際にカードとして扱う枚数
- `横間隔 %` / `縦間隔 %`: 領域サイズに対するカード間隔
- `カード幅/高さ`: カード比率。初期値は `0.686`

白枠がメインデッキ、橙枠がEXデッキです。公式ツール画像の解像度や余白により初期値がずれる場合は、プレビューを見ながら調整してください。

切り出したカード画像は、外周を削らず長方形のまま表示します。表示上のトリミングで角や端が欠けないよう、保存画像の実寸比率を優先します。
